# 가이드 초안 만들기

가이드는 자동으로 올라오지 않습니다. 아래 순서로 직접 만듭니다.

## 순서

1. 사이트의 뉴스 중 "따라 해볼 만한 것"을 하나 고릅니다.
2. 아래 프롬프트를 ChatGPT 등에 붙여 넣고, 맨 아래에 원문 링크와 공식 문서 링크를 넣습니다. 웹 검색이 켜진 상태로 씁니다.
3. 나온 초안을 `src/content/guides/<영문-이름>.md`로 저장합니다. 이 시점에는 `verifiedAt`을 넣지 않습니다.
4. **처음부터 끝까지 직접 따라 해봅니다.** 틀린 단계를 고치고 `[확인 필요]` 표시를 모두 없앱니다.
5. 다 되면 맨 위에 `verifiedAt: YYYY-MM-DD`(따라 해본 날짜)를 추가하고 올립니다.

`verifiedAt`이 없는 가이드는 사이트에 나오지 않습니다. 따라 해보지 않은 글에 날짜를 넣지 마세요.

로컬에서 초안 모습을 보려면: `PUBLIC_SHOW_DRAFTS=true npm run dev`

## 프롬프트

```text
너는 AI를 잘 모르는 한국 직장인을 위한 "따라하기 설명서"를 쓰는 편집자야.
아래 링크의 내용을 읽고, 비전공자가 30분 안에 그대로 따라 할 수 있는 가이드를 써 줘.

규칙:
- 가전제품 사용설명서처럼 쓴다. 한 단계에 한 가지 행동만 적는다.
- 중학생도 이해할 말로 쓴다. 전문용어는 처음 나올 때 괄호로 풀이한다.
- 메뉴 이름과 버튼 이름은 네가 직접 읽은 공식 문서에 있는 그대로 적는다.
  확인하지 못한 이름이나 위치는 추측하지 말고 [확인 필요]라고 적는다.
- 단계마다 "이렇게 보이면 성공"을 한 줄로 덧붙인다.
- HTML은 쓰지 않는다. 마크다운만 쓴다.
- 네가 읽은 문서의 주소를 "참고 링크"에 모두 적는다.

아래 형식 그대로 출력해. 제목 다섯 개의 이름과 순서를 바꾸지 마.

---
title: "무엇을 하는 가이드인지 한 줄"
roles: ["개발자", "디자이너", "기획·PM", "마케터", "일반 사무" 중 해당하는 것만]
difficulty: "쉬움" 또는 "보통" 또는 "어려움"
minutes: 걸리는 시간(분, 숫자만)
tools: ["필요한 서비스나 프로그램"]
---
```
